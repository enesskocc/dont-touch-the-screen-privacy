Privacy Policy for Don't Touch The Screen

Don't Touch The Screen collects only the data needed to provide the app’s core functionality.

Data We Collect

  • Username entered by the user
  • Score/time submitted to the global leaderboard

How We Use This Data

  • To display leaderboard rankings
  • To show the user’s submitted score inside the app

Data Sharing

  • We do not sell user data
  • We do not use user data for tracking
  • We do not use user data for advertising in the current version

Storage

Leaderboard data is stored using Firebase Firestore.

User Choices

  • Users choose whether to submit a score
  • If a user does not submit a score, no leaderboard entry is created
